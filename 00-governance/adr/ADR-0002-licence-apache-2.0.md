# ADR-0002: Repository licence — Apache-2.0

- **Status:** Accepted
- **Date:** 2026-05-29

## Context
Charter Part 1/20 mandates open-source-only dependencies with permissive/compatible licences and a recorded inventory.

## Decision
License the Illumin360 source under **Apache-2.0** (permissive, patent grant). All dependencies must be
MIT/Apache-2.0/BSD/MPL-2.0 or compatible; each is recorded in `00-governance/licenses/`.

## Consequences
**Positive:** Permissive, patent protection, widely compatible.
**Negative:** Must replace the LICENSE stub with the full Apache-2.0 text before public release.
